# Issue tracker — ISRAA Hub

Issues live in **GitHub Issues** for `0uss4m4/ISRAA-HUB`, managed via the `gh` CLI.

- Create: `gh issue create --title "<title>" --body "<body>" --label needs-triage`
- List: `gh issue list --label <label>`
- View: `gh issue view <number>`

**PRs as a request surface:** off.
