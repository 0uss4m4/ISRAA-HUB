# Domain docs — single-context

- Glossary: root `GLOSSARY.md` — read it first for canonical terms (DSI, RSSI, lead, license key, regulatory delta).
- ADRs: `docs/adr/<nnnn>-<slug>.md` — check before introducing new patterns.

Consumer rules: use glossary terms verbatim; cite the ADR number when applying a recorded decision; write a new ADR when deviating.
