# Triage labels

Default canonical vocabulary. Each label string equals its role name.

| Role | Label |
|---|---|
| Incoming, unclassified | `needs-triage` |
| Waiting on reporter input | `needs-info` |
| Ready for agent work | `ready-for-agent` |
| Needs human decision | `ready-for-human` |
| Out of scope | `wontfix` |
